# 🎓 Student Management Application (Spring Boot)

This is a backend-only **Spring Boot project** for managing students, built as part of my Spring Boot learning journey at **AccioJob** 🚀

## 🧩 About
- Built using **Spring Boot**
- Follows REST API design principles
- Tested using **Postman** (no frontend integration)
- Demonstrates CRUD operations on Student entities (Create, Read, Update, Delete)

## ⚙️ Tech Stack
- Java ☕
- Spring Boot 🌿
- Spring Data JPA 🧠
- Postman for API testing 📬

## 🧠 Learning Goals
- Master Spring Boot backend development
- Learn API creation, service layers, and data persistence
- Understand application flow and structure
